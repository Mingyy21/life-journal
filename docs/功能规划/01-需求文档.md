# 需求文档 — 人生展望 & 感悟关系

---

## 功能一：人生展望

### 1.1 背景

用户在"生活意义"领域下记录关于未来的想法、理想生活的想象。这些记录零散分布在日记中，缺乏整合。需要一个功能将这些碎片汇总成一篇完整的人生展望文章，并拆解出需要面对的各课题底线。

### 1.2 用户故事

| ID | 故事 | 优先级 |
|----|------|--------|
| US1 | 作为用户，我希望集中看到我对未来生活的所有畅想 | P0 |
| US2 | 作为用户，我希望 AI 基于我的记录帮我润色成一篇文章 | P0 |
| US3 | 作为用户，我希望 AI 从愿景中识别出需要面对的课题 | P0 |
| US4 | 作为用户，我希望为每个课题设定一条底线（最低接受标准） | P0 |
| US5 | 作为用户，我希望随时能看到自己的人生展望和所有底线 | P0 |
| US6 | 作为用户，我希望修改记录后能重新生成（覆盖或另存） | P1 |
| US7 | 作为用户，我希望展望页面能直观看到各课题的进度状态 | P1 |

### 1.3 功能性需求

#### F1.1 人生理想课题

- 系统预置"人生理想"课题，归属"生活意义"领域
- 课题下预置"人生展望"事件，作为所有展望相关记录的容器

#### F1.2 首次引导

- 用户首次进入人生理想课题时，弹出引导流程：
  1. 扫描该课题下的现有日记和感悟
  2. 如果已有内容 → 询问"是否基于已有内容生成展望"
  3. 如果已有类似展望文章/底线 → 展示让用户选择认定
  4. 如果无内容 → 引导用户先在日记中记录想法

#### F1.3 AI 生成展望

- 用户点击"生成展望"后：
  1. 读取人生理想课题下所有日记 + 关联日记
  2. 调用 DeepSeek API 生成一篇连贯的人生展望文章（500-1500字）
  3. 同时提取需要面对的课题列表及建议底线
- 生成结果保存为两条特殊类型的感悟

#### F1.4 展望文章（特殊感悟）

- 新增 `insight.type = "vision"` 的感悟，存放 AI 生成的文章
- 文章使用 Markdown 渲染，可手动编辑
- 重新生成时弹窗让用户选择：覆盖 / 另存为新版

#### F1.5 课题底线（特殊感悟）

- 每条底线保存为 `insight.type = "baseline"` 的感悟
- 关联到对应的课题（通过 `linkedTopicIds`）
- 每个课题最多一条底线

#### F1.6 人生展望页面

- 独立页面 `/vision`，永久入口
- 展示内容：
  - 顶部：人生展望文章（全宽 Markdown 渲染）
  - 中部：Sunburst Wheel 可视化（各课题进度）
  - 底部：各课题底线卡片列表

#### F1.7 Sunburst Wheel 可视化

- 中心：用户人生愿景
- 扇区：每个被识别的课题
- 三层环：
  - 内层：课题名称 + 优先级权重
  - 中层：底线符合度颜色（绿/黄/红）
  - 外层：记录活跃度填充比例
- 交互：点击扇区展开详情

## 功能二：感悟关系

### 2.1 背景

用户积累了大量感悟后，这些感悟之间缺乏关联。一个深层认知往往由多个子感悟支撑，有时存在矛盾的观点。需要建立感悟之间的关系网络，帮助用户看清自己的思维脉络。

### 2.2 用户故事

| ID | 故事 | 优先级 |
|----|------|--------|
| US8 | 作为用户，我希望把两条感悟关联起来，表达它们之间的关系 | P0 |
| US9 | 作为用户，我希望能看到一条感悟的上/下级脉络 | P0 |
| US10 | 作为用户，我希望能标记两条感悟是相反立场 | P0 |
| US11 | 作为用户，我希望能从一张图上看到所有感悟的关系网 | P1 |
| US12 | 作为用户，我担心误触，希望有撤销机制 | P0 |

### 2.3 功能性需求

#### F2.1 关系类型

| 类型 | 含义 | 示例 |
|------|------|------|
| parent | 上级（更抽象的认知） | "我的人生观" ← parent ← "工作不是全部" |
| child | 下级（具体支撑） | "工作不是全部" → child → "我不加班后更快乐" |
| sibling | 平级（并列的观点） | "我不加班后更快乐" ← sibling → "减少社交反而更充实" |
| opposite | 反面（矛盾/对立） | "社交是能量的来源" ← opposite → "独处才是充电方式" |

#### F2.2 关系创建

- 默认在感悟卡片列表或详情页操作
- 两种触发方式：
  - 长按/右键感悟卡片 → 弹出菜单 → "链接到其他感悟"
  - 感悟详情页底部 → "添加关联"
- 进入链接模式后：
  - 展示可选感悟列表（搜索/筛选）
  - 点击目标感悟 → 弹出关系类型选择 → 确认完成链接

#### F2.3 防误触

- 链接完成后显示 toast："已链接 A → [关系] → B"，3秒可撤销
- 每条关系旁有"解除链接"按钮
- 关系列表可管理、删除

#### F2.4 关系展示

- 感悟详情页底部显示所有关联关系：
  - 上级：展示在上方（缩进少）
  - 下级：展示在下方（缩进多）
  - 平级：并列显示
  - 反面：红色虚线分隔
- 全局关系图（P1）：用简单的力导向图展示所有感悟网络

#### F2.5 限制

- 不允许自链接
- 不允许重复关系（A→B 已经 parent，不能再建 sibling）
- 无环检测（A→B 是 child，B→A 不能也是 child）

## 3. 非功能性需求

| ID | 需求 | 说明 |
|----|------|------|
| NFR1 | 响应速度 | AI 生成展望应在 15 秒内返回，超过则显示进度提示 |
| NFR2 | 数据安全 | 关系数据不涉及敏感信息，遵循现有 RLS 策略 |
| NFR3 | 兼容性 | 不破坏现有感悟/日记/事件的任何功能 |
| NFR4 | 低侵入 | 不修改现有 insight 表结构，用新表/新字段做扩展 |

---

## 4. 接受标准

### 人生展望

- [ ] 用户能从导航进入人生展望页面
- [ ] 首次进入时能检测已有内容并引导
- [ ] AI 能基于日记生成合理的展望文章
- [ ] AI 能提取出课题并建议底线
- [ ] 用户能手动编辑展望文章
- [ ] 重新生成时弹出覆盖/另存选择
- [ ] 每个课题的底线在对应课题页可见

### 感悟关系

- [ ] 用户能通过长按/右键创建关系
- [ ] 四种关系类型（parent/child/sibling/opposite）都能正常创建
- [ ] 防误触撤销机制生效
- [ ] 感悟详情页正确显示关联关系
- [ ] 不允许自链接和重复链接
- [ ] 解除链接后数据正确清除
