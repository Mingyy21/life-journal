## 一、人生展望 — 设计

### 1.1 信息架构

```
生活意义（领域）
  └─ 人生理想（课题）
       ├─ 日记（用户写的碎片想法）
       ├─ 人生展望（事件）
       │    ├─ 展望文章（insight.type=vision）
       │    └─ 课题底线列表
       │         ├─ 人际底线（insight.type=baseline, linkedTopicId=...）
       │         ├─ 工作底线（insight.type=baseline, linkedTopicId=...）
       │         └─ ...
       └─ 人生展望页面 /vision（独立路由）
            ├─ 文章展示区
            ├─ Sunburst Wheel 可视化
            └─ 底线卡片列表
```

### 1.3 Sunburst Wheel 设计

```
         ┌──────────────────────────┐
         │     外层：活跃度          │
     ┌───┤    (填充比例)            ├───┐
     │   └──────────────────────────┘   │
     │   ┌──────────────────────────┐   │
     ├───┤     中层：底线符合度      ├───┤
     │   │    (绿/黄/红 颜色)       │   │
     │   └──────────────────────────┘   │
     │   ┌──────────────────────────┐   │
     ├───┤ 内层：课题名称 + 优先级   ├───┤
     │   └──────────────────────────┘   │
     │              🎯                  │
     │           人生愿景               │
     └──────────────────────────────────┘
```

- **中心圆**：显示"人生愿景"或用户头像
- **每层环宽度**：约 30px
- **颜色体系**：
  - 内层：课题本身颜色
  - 中层：🟢 #22c55e / 🟡 #eab308 / 🔴 #ef4444
  - 外层：同课题颜色，透明度随比例填充

### 1.4 交互设计

| 操作 | 行为 |
|------|------|
| 点击扇区 | 展开详情面板（底线 + 最近记录 + 去课题按钮） |
| 悬停扇区 | 高亮该扇区所有环层 + tooltip 显示课题名和数据 |
| 点击中心 | 弹出人生展望文章 |
| 点击"重新生成" | 弹窗选择覆盖/另存 → loading → 完成 |
| 点击"编辑文章" | 原地切换为可编辑文本框 |

## 二、感悟关系 — 设计

### 2.1 关系模型

```
[感悟 A]
   ├─ parent ──▶ [感悟 B]（B 是 A 的上级概念）
   ├─ child ───▶ [感悟 C]（C 是 A 的下级支撑）
   ├─ sibling ─▶ [感悟 D]（D 和 A 是并列观点）
   └─ opposite ─ [感悟 E]（E 和 A 立场相反）
```

关系是**双向存储**的：A→B parent 自动创建 B→A child。

### 2.2 卡片操作设计

#### 长按/右键菜单

```
[感悟卡片]
    ↓ 长按 / 右键
┌────────────────┐
│  链接到其他感悟  │ ← 进入链接模式
│  编辑           │
│  删除           │
└────────────────┘
```

#### 链接模式

```
┌─────────────────────────────────────────┐
│  选择要链接的感悟：                        │
│  ┌─── 搜索框 ────────────────────────┐  │
│  │  搜索感悟标题...                    │  │
│  └────────────────────────────────────┘  │
│                                          │
│  全部感悟                                │
│  ┌────────────────────────────────────┐  │
│  │ ◻ 我不加班后更快乐                  │  │
│  │ ◻ 社交是能量的来源                  │  │
│  │ ◻ 减少社交反而更充实    ● ← 选中    │  │
│  │ ◻ 工作不是全部                      │  │
│  └────────────────────────────────────┘  │
│                                          │
│  ── 选择关系类型 ──                       │
│  [上级] [下级] [平级] [反面]  [取消]     │
└─────────────────────────────────────────┘
```

### 2.3 关系展示

#### 感悟详情页

```
┌── 感悟：我不加班后更快乐 ──────────────┐
│  内容...                                │
│                                         │
│  ── 关联关系 ──                         │
│                                         │
│  上级：                                  │
│    ┌─ 工作不是全部 ─┐                   │
│    │  更抽象的认知   │ ← 缩进少         │
│    └────────────────┘                   │
│                                         │
│  下级：                                  │
│      ┌─ 减少社交后反而充实 ─┐           │
│      │  具体的实践验证     │ ← 缩进多   │
│      └────────────────────┘             │
│                                         │
│  反面：                                  │
│    ╔═ 社交是能量的来源 ═╗ ← 红色虚线框 │
│    ║  相反立场          ║              │
│    ╚════════════════════╝              │
│                                         │
│  [+ 添加关联]                           │
└─────────────────────────────────────────┘
```

#### 全局关系图（P1）

用力导向图布局，每个节点是一条感悟，边是关系类型，不同颜色区分：

```
         [A] ──parent──▶ [B]
          │                │
       sibling           child
          │                │
         [C] ◀──opposite── [D]
```

### 2.4 防误触设计

- 创建链接后：toast 显示"已链接 A → 上级 → B **[撤销]**"，3秒
- 撤销后：恢复原状，toast 消失
- 每条关系卡片右上角有 **× 解除** 按钮
- 解除前弹出确认："确定解除这条关系？"

### 2.5 约束规则

| 规则 | 实现方式 |
|------|---------|
| 不自链接 | 选择列表排除当前感悟 |
| 不重复关系 | 创建前检查是否已有相同 relation |
| 无环检测 | A→B 后禁止 B→A 的同类型关系 |
| 关系数上限 | 单条感悟最多 20 条关联（防过度复杂） |
