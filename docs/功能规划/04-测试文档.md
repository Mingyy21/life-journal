## 三、回归测试

| 编号 | 场景 | 验证点 |
|------|------|--------|
| R1 | 现有感悟 CRUD 不受影响 | 创建/编辑/删除感悟正常 |
| R2 | 现有事件 CRUD 不受影响 | 创建/编辑/删除事件正常 |
| R3 | 现有日记 CRUD 不受影响 | 写日记/保存/编辑/删除正常 |
| R4 | 现有课题 CRUD 不受影响 | 课题列表/详情正常 |
| R5 | 现有 AI 分析不受影响 | AI 分析正常触发和展示 |
| R6 | insight_relations 表 RLS | 不同用户看不到对方的关系数据 |
| R7 | 批量加载性能 | 50 条感悟页面加载 < 2s |
| R8 | 关系较多时不影响感悟列表 | 感悟列表不因关系数据变慢 |
